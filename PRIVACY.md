# RoAvatar Privacy Policy
**Last updated: 08/09/2026 (8. september 2026)**

RoAvatar is designed to operate locally on your device and to respect your privacy. This policy explains what data the extension collects, how that data is used, and how it is protected.

## 1. Contact
If you have questions or requests, contact: support@roavatar.net

## 2. Information We Collect
### 2.1 Local Data (stored on device)
RoAvatar stores a small amount of data on your device using the browser’s storage system. This may include:
- Extension settings
- Local outfits
- Other data required for core functionality

### 2.2 Sent to API (stored on server)
Some features marked with (API) require contacting a server through an API, they can be disabled in settings. Certain features like avatar history may result in the backend server validating and possibly updating stored data before sending it back, while others result in no changes on the backend.

The extension may send:
- Roblox user IDs
- Roblox item IDs
- RoAvatar avatar IDs
- Avatar search queries

No personally identifiable information is ever sent to the API.

## 3 Backend Storage
### 3.1 Long-term Data
The backend stores avatar data, not any personal data. This data only exists to power features such as avatar history, avatar search or other similar features.

### 3.2 Short-term data
The backend may store IP addresses and request timestamps for short periods of time. This data is only used to prevent abuse and allow for rate-limiting (preventing the API from being overwhelmed).

## 4. How We Use This Data
All data stored by RoAvatar is used solely to provide core functionality, such as:
- Providing core functionality
- Getting avatar information
- Getting avatar history
- Allowing for avatar searching

## 5. Data Sharing
RoAvatar does not share any data with third parties.

## 6. Data Security
- Local data always remains on your device
- No personal data is ever transmitted
- Backend data is secured and can only be accessed through API requests, in addition no sensitive data is ever stored

## 7. User Rights (GDPR)
Users located in the EU/EEA have the right to:
- Request access to data we store
- Request deletion of stored data
- Request correction of inaccurate data
- Request limitation of processing
- File a complaint with their local data protection authority

Any requests or inquires can be sent to support@roavatar.net

## 8. Children's Privacy
RoAvatar does not collect personal information from any users, including children.

## 9. Changes to This Policy
If RoAvatar’s data handling practices change in the future, this privacy policy will be updated accordingly.
